# Shop Directory

The Shop Directory lets you search every player chest shop on Survival by item — without having to walk around and find them yourself.

It's available in two places:

## On the Website

Go to [craftingforchrist.net/shopdirectory](https://craftingforchrist.net/shopdirectory) and search by **Material** (the item being bought or sold, minimum 2 characters).

Each result shows the seller's username, item quantity, price, stock status, and the shop's in-game coordinates so you can navigate straight to it.

## In Discord

Use the `/shopdirectory` command in Discord:

```
/shopdirectory material:<item> [type:buying|selling]
```

Results appear as a paginated embed, up to 8 shops per page, with the same seller/price/stock/coordinate info as the website. Use the buttons to page through results.

:::note

The directory pulls live data directly from shops set up in-game — there is no separate in-game command for it. If a shop doesn't show up, make sure it's a properly created [Player Chest Shop](./create-shop.md).

:::
