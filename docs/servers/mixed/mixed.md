# Mixed

<Persona who="finn">
  Win because you played better, not because you bent the game.
</Persona>

Mixed is our competitive, team-based server, powered by [PGM](https://pgm.dev) (PvP Game Manager). Instead of one persistent world, you play rounds on a rotation of maps, each with its own teams, spawns and objectives. When a match ends, the server cycles to the next map and a new round begins.

The name comes from PGM itself: a *Mixed* map is one that combines several objective types in a single round, so you might be destroying a monument, capturing wool and holding a point all at once. Expect variety - a lot of different gamemodes come through the rotation.

Everything on this server still sits inside the same community you'll find on the rest of the Network: play hard, play fair, and be good to the people on the other team as well as your own.

## Choosing and Reading a Map

Type `/map` to see the current map and its objectives, or `/maps` to browse everything in rotation. Some maps have rules that apply only to that map - read them under `/map` before you assume a tactic is allowed. A map-specific rule overrides the general expectation for that round.

Between matches you can vote on what plays next. See the [Command Reference](./commands.md) for the voting and map commands.

## Playing Fair

The same anti-cheat expectations as the rest of the Network apply here: no cheat clients, no exploiting bugs, and no mods that give you an unfair advantage. Because Mixed is competitive, a handful of mods that are fine on Survival are **not** allowed here - minimaps, damage indicators, automatic tool selectors and a few others. See [Mixed Server: Extra Restrictions](../../general/mods-and-clients.md) for the full list.

Found a bug or exploit? Report it instead of using it. See [I found a bug!](../../general/found-bug.md).
