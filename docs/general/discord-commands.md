# Discord Command Index

These slash commands are available to everyone in our Discord server.

| Command | Description |
| ------- | ----------- |
| /play | Display all Network servers to play on. |
| /apply | Display information about staff applications. |
| /rules | Display a link to the Network rules. |
| /website | Display a link to the Network website. |
| /policy | Display links to all Network policies (Rules, Terms, Privacy, Refund). |
| /report \<user\> \<reason\> | Report a Discord user for misconduct or breaking the rules. |
| /poll \<question\> | Create a poll for others to vote on. |
| /profile [username \| discord_user] | View your profile, or another player's, showing their linked account info. |
| /ranks | Display a link to view rank perks and donate. |
| /shopdirectory material:\<item\> [type:buying\|selling] | Search player chest shops by item. See the [Shop Directory](../servers/survival/shops/shop-directory.md) page for details. |
| /support create | Open a new support ticket. |
| /support submit | Submit a support ticket. |

:::note

Some commands only work if the related feature is enabled by staff (for example, `/shopdirectory` requires the Shop Directory feature). If a command says a feature is disabled, that's expected — it isn't an error on your end.

:::
